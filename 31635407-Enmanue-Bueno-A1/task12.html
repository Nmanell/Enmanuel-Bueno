Documentation

2a: The circle geometry for triangle fan rendering is calculated by using a formula to compute the x and y coordinates of a point on the edge of a circle with the segments being used to divide the circle into evenly spaced angles around the cicle, and setting the center at the origin (0, 0). 2b: Since webgpu does not support the triangle fan rendering pipeline, triangle list is used instead for the circle fill and line strip is used for the circle outline. When the frame is rendered for the circle outline, the first vertex is skipped since it is set as the center of the circle which should not be included in the outline. Additionally, when creating the buffer to be used for rendering, the color of these points are changed to be black instead of the rgb colors used to create the gradient. The buffer used for rending the circle's fill is modified from the one created in circlegeometery since triangle fan rending cannot be used. The new buffer consists of sets of three vertices, the origin, an outer vertex and the next outer vertex in the sequence. This replicates the triangle fan effect using the triangle list rendering pipeline. 2c: The displayed circle is not round since it is actually made up of many triangles and is not a real circle. This can be seen when the segment count is low with the slider's lowest segment count being a triangle. Howver, when the segment count is high, the edges of the polygon are so small that it appears to be a circle.
