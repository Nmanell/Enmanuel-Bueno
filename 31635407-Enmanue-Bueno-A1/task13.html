Documentation

3a: Following a similar procedure to the recursion used in task 1a but adapted to an object with 4 vertices. As a result, changing of the lambda values affects the object in a similar way except color is not affected by lambda in this task. Lambda changes the ratio between points causing the point created during division to be closer to one point than another depending on whether lambda is closer to 0 or 1. This can cause some faces to over lap when the recursion count is high. 3b: The vertex stage was modified to take a 3 dimensional vector as an input. This 3 dimensional vector is then passed to the output with the z-axis being changed to fit the [0, 1] clips space used by WEBGPU. 3c: Changes where made in array size, count, and stride to account for the additional z axis that each vertex now needs to store. 3d: The division of the vertex size to calculate the vertex count was changed to account for the additional positional data point that the vertex now needs to store.
